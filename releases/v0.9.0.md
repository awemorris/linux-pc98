# Linux/PC-98 v0.9.0

This release introduces **Boots**, the PC-98 boot loader and pre-boot
environment. Boots embeds the Noct language runtime, interpreter, lightweight
i386 JIT, REPL, software floating-point support, native APIs, and a graphical
boot environment. The release was built with Noct commit `783f481`.

It retains the v0.8.0 networking additions: the traditional `ifconfig`
command is available in both distributed userlands. The i386 BusyBox images
provide the built-in BusyBox applet, and the Debian 13/i486 images install the
`net-tools` implementation. It also retains the IDE and SCSI Linux 7.1 images,
replaceable BOOT98 boot chain, standalone kernels, and Windows x64 qemu-pc98
distribution introduced in v0.7.0.

Public disk images use the GDC display and PC-98 keyboard as the console. The
PC-9801-55/92 Linux driver is built into the i386 and i486 kernels.

## Choosing a disk image

| Image | CPU and userland | Interface and geometry | Minimum RAM | Raw size limit |
| --- | --- | --- | ---: | ---: |
| `linux-pc98-i386sx-busybox-ide.img.xz` | i386SX, static BusyBox | IDE, H=8/S=17 | 5 MiB | below 160 MiB |
| `linux-pc98-i386sx-busybox-scsi55.img.xz` | i386SX, static BusyBox | PC-9801-55 compatible SCSI, H=8/S=17 | 5 MiB | below 160 MiB |
| `linux-pc98-i386sx-busybox-scsi92.img.xz` | i386SX, static BusyBox | PC-9801-92 SCSI, H=8/S=32 | 5 MiB | below 160 MiB |
| `linux-pc98-i486dx-debian13-ide.img.xz` | i486DX or newer, Debian 13/i486 | IDE, H=8/S=17 | 64 MiB | below 2 GB |
| `linux-pc98-i486dx-debian13-scsi55.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-55 compatible SCSI, H=8/S=17 | 64 MiB | below 2 GB |
| `linux-pc98-i486dx-debian13-scsi92.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-92 SCSI, H=8/S=32 | 64 MiB | below 2 GB |

Write the appropriate decompressed image to a CF card, SD adapter, SCSI2SD,
BlueSCSI, or another block device. Writing an image destroys the existing
contents of the destination device.

Every image has a 128 MiB FAT16 BOOT partition containing a 64 MiB zedBSD
`/swapfile`. This file is independent of the Linux swap partition.

## Boots pre-boot environment

Boots can run Noct scripts from FAT16 volumes and provides a Unix-style
mounted-disk namespace, persistent environment variables, file access,
terminal input/output, and convenience functions such as `print()` and
`gets()`. Included scripts provide `ls` and `cp`; `noct` starts the interactive
REPL; and `emacs FILE` starts the packaged Remacs bytecode editor.

The optional BeUI environment provides a keyboard-operated graphical boot
menu on PC-98 GDC and Cirrus displays, PC-98 font-ROM glyph rendering,
Japanese text support, and safe return to the text console. If graphical
startup is unavailable, Boots retains its traditional text menu and
interactive shell.

`bootloader.zip` now also includes `AUTOEXEC.NCT`, example Noct commands,
`CMD/REMACS.NAP`, Remacs configuration, the SKK dictionary, and the applicable
Noct and software floating-point license notices.

### Known issue

The interactive Noct REPL is experimental in v0.9.0. It starts successfully,
but can freeze during use. This does not prevent Boots from running Noct
scripts or packaged applications directly.

## Networking tools

Both userlands now include `ifconfig`. Debian also continues to include
`ip`, `ping`, `wget`, and the OpenSSH server. Network interfaces are not
configured automatically when no interface configuration is present, which
prevents unnecessary boot delays on machines without a LAN adapter.

## Windows qemu-pc98

- `qemu-pc98-win64.zip` contains x86_64 and i386 QEMU system binaries,
  required runtime DLLs, libusb support, and the free compatibility BIOS.
- `virtpc98.exe` is included as the graphical frontend.

## Kernels and boot loaders

- `vmlinux-i386` is the low-memory Linux 7.1 kernel for i386SX systems.
- `vmlinux-i486-debian` is the Linux 7.1/i486DX kernel used by the Debian
  images.
- `bootloader.zip` contains `LINUX98.EXE`, `INST.EXE`, the three `.IMG`
  installer inputs, `IO.SYS`, `BOOT.SYS`, `BOOT.CFG`, and documentation.

## Boot from DOS

Copy `LINUX98.EXE` and an uncompressed `VMLINUX` to a DOS-accessible FAT
volume and run, for example:

```text
LINUX98 VMLINUX ide0 root=PARTLABEL=LINUXROOT rw
LINUX98 VMLINUX scsi0 root=/dev/sda2 rw
```

Run it from plain real-mode DOS. Memory managers or other software that has
already entered protected mode can prevent the loader from taking control.

`INST.EXE` installs the replaceable disk and partition boot components:

```text
INST /LBA0
INST /LBA2
INST /PART C:
```

Read `README.md` and `DOS-README.md` in `bootloader.zip` before installation.

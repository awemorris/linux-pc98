# Linux/PC-98 v0.13.0

This release moves the PC-98 kernels to Linux 7.2, adds a usable X11 desktop
to the Debian 13/i486 images, and expands qemu-pc98 and VirtPC98 for SMP and
runtime device control.

## Highlights

- Linux 7.2 is now used by both the i386SX BusyBox and i486DX Debian images.
  The complete Linux 7.1 source tree remains in the repository for reference
  and regression comparison.
- The PC-98 patch set was rebased onto Linux 7.2, including the legacy math
  emulation required by the 80386 target.
- The PC-9821 Core-Graph Cirrus framebuffer supports the real hardware path
  used by systems such as the PC-9821V13. The Debian images expose it as
  `/dev/fb0` and run Xorg through the fbdev driver.
- Debian 13/i486 now includes Xorg, xterm, twm, the evdev input driver, and
  `xoppai`, an interactive X11 curve demonstration.
- PC-98 keyboard and bus-mouse support are built into the Debian kernel and
  are bound explicitly as Xorg core input devices. This avoids dependence on
  udev input classification on the minimal SysV root filesystem.
- Xorg accepts the non-PCI Core-Graph framebuffer and preserves its packed
  24-bpp hardware layout while using the driver's 32-to-24 shadow conversion.
- The Debian IDE image now uses bootsimple for direct BIOS kernel loading.
  The SCSI55 and SCSI92 images retain the zedBSD graphical boot menu.
- bootsimple restores its unreal-mode selector after BIOS calls, making BIOS
  kernel loading robust when an option ROM or interrupt handler saves and
  restores `FS` in real mode.
- qemu-pc98 adds SMP support and additional Cirrus/PEGC fixes. VirtPC98 adds
  CPU and core selection, 64-bit executable selection, snapshot mode, and
  QMP-based floppy replacement while the VM is running.

## Choosing a disk image

| Image | CPU and userland | Interface and geometry | Bootloader | Minimum RAM |
| --- | --- | --- | --- | ---: |
| `linux-pc98-i386sx-busybox-ide.img.xz` | i386SX, static BusyBox | IDE, H=8/S=17 | bootsimple | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi55.img.xz` | i386SX, static BusyBox | PC-9801-55 compatible SCSI, H=8/S=17 | bootsimple | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi92.img.xz` | i386SX, static BusyBox | PC-9801-92 SCSI, H=8/S=32 | bootsimple | 5 MiB |
| `linux-pc98-i486dx-debian13-ide.img.xz` | i486DX or newer, Debian 13/i486 with X11 | IDE, H=8/S=17 | bootsimple | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi55.img.xz` | i486DX or newer, Debian 13/i486 with X11 | PC-9801-55 compatible SCSI, H=8/S=17 | zedBSD | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi92.img.xz` | i486DX or newer, Debian 13/i486 with X11 | PC-9801-92 SCSI, H=8/S=32 | zedBSD | 64 MiB |

Write the appropriate decompressed image byte-for-byte to a CF card, SD
adapter, SCSI2SD, BlueSCSI, or another block device. Writing an image destroys
the existing contents of that device.

## X11 on the Debian images

Log in as `root` with password `pc98`, then run:

```sh
startx
```

The default session starts twm, xterm, and the `xoppai` demonstration. The
kernel provides the native keyboard and bus mouse through `/dev/input/event0`
and `/dev/input/event1`.

## SCSI support

The Linux 7.2 kernel contains the common PC-9801-55/92 WD33C93 driver. The
selected release image supplies the corresponding `pc9801_scsi=55` or
`pc9801_scsi=92` kernel parameters and matching disk geometry.

## Other artifacts

- `vmlinux-i386` is the Linux 7.2 low-memory kernel for i386SX systems.
- `vmlinux-i486-debian` is the Linux 7.2/i486DX Debian kernel.
- `bootsimple.zip` contains the IDE/SCSI55/SCSI92 direct loaders, source,
  installer, verifier, tests, and exact release command lines.
- `bootloader.zip` contains the zedBSD PC-98 loader distribution and DOS tools.
- `qemu-pc98-win64.zip` contains Windows qemu-pc98 binaries, compatibility
  BIOS, required DLLs, and the VirtPC98 frontend.
- `SHA256SUMS` authenticates every uploaded binary artifact.

## Reproducible build

The complete release artifact set is generated with:

```sh
./build.sh release --version v0.13.0
```

The release uses zedBSD commit `e4a2c2b`, qemu-pc98 commit `c408026`, and
debian-i486 commit `ff24fb8`.

# Linux/PC-98 v0.10.0

This release separates the two public boot paths. The compact i386SX BusyBox
images now use **bootsimple**, an assembly-only PC-98 loader which enters Linux
directly. The Debian 13/i486 images retain **zedBSD**, its graphical Noct menu,
Remacs editor, and Holoris demo.

## Highlights

- BusyBox IDE and SCSI images boot directly through bootsimple, without loading
  the zedBSD/Noct environment. The loader reports each stage on the PC-98 text
  display and passes BIOS disk geometry to Linux.
- Debian images keep the zedBSD graphical menu. Selecting Linux now waits for
  disk discovery and mounts the actual `PARTLABEL=DEBIAN13` root filesystem.
- Generated IDE images use H=8/S=17 by default for real-machine compatibility.
  H=4 is reserved for explicitly requested legacy images; the compatible QEMU
  BIOS selects H=4 only for disks of 20 MiB or less.
- The BusyBox images preserve the 5 MiB minimum-memory target and now reserve a
  128 MiB BOOT partition, keeping each raw image below 160 MiB.
- Remacs bytecode and its SKK dictionary are generated as part of the image
  build. Overlay installation is flushed and verified before an image replaces
  the canonical release file.
- The repository layout and build scripts were reorganized around `external/`
  submodules, `bootsimple/`, the zedBSD product overlay, and canonical
  `release-image` profiles.

## Choosing a disk image

| Image | CPU and userland | Interface and geometry | Minimum RAM |
| --- | --- | --- | ---: |
| `linux-pc98-i386sx-busybox-ide.img.xz` | i386SX, static BusyBox | IDE, H=8/S=17 | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi55.img.xz` | i386SX, static BusyBox | PC-9801-55 compatible SCSI, H=8/S=17 | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi92.img.xz` | i386SX, static BusyBox | PC-9801-92 SCSI, H=8/S=32 | 5 MiB |
| `linux-pc98-i486dx-debian13-ide.img.xz` | i486DX or newer, Debian 13/i486 | IDE, H=8/S=17 | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi55.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-55 compatible SCSI, H=8/S=17 | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi92.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-92 SCSI, H=8/S=32 | 64 MiB |

Write the appropriate decompressed image to a CF card, SD adapter, SCSI2SD,
BlueSCSI, or another block device. Writing an image destroys the existing
contents of that device.

## Boot behavior

BusyBox images load `VMLINUX` directly from the FAT16 BOOT partition through
bootsimple. Debian images boot zedBSD first and offer Linux, Remacs, Holoris,
and a shell in the graphical menu.

The Debian Linux action is:

```text
/bin/linux /vmlinux root=PARTLABEL=DEBIAN13 rootfstype=ext4 rw rootwait
```

The Debian IDE image has been tested through the production graphical menu to
the ext4 root mount, runlevel 2, OpenSSH startup, and root shell prompt.

## Other artifacts

- `vmlinux-i386` is the low-memory Linux 7.1 kernel for i386SX systems.
- `vmlinux-i486-debian` is the Linux 7.1/i486DX Debian kernel.
- `bootloader.zip` contains the zedBSD PC-98 loader distribution and DOS tools.
- `qemu-pc98-win64.zip` contains the Windows qemu-pc98 binaries, compatibility
  BIOS, required DLLs, and the VirtPC98 frontend.
- `SHA256SUMS` authenticates every uploaded binary artifact.

## Reproducible build

The complete release artifact set is generated with:

```sh
./build.sh release --version v0.10.0
```

The release uses zedBSD commit `05ee0f5`, Noct commit `487ddfc`, qemu-pc98
commit `46f7016`, and debian-i486 commit `a1e431e`.

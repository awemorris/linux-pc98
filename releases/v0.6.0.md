# Linux/PC-98 v0.6.0

This release provides Linux 7.1 disk images for NEC PC-9800 machines, a
Windows x64 build of qemu-pc98, and standalone kernels and boot-loader files.
Public disk images use the GDC display and PC-98 keyboard as the console.

## Choosing a disk image

| Image | CPU and userland | Interface and geometry | Minimum RAM | Raw size limit |
| --- | --- | --- | ---: | ---: |
| `linux-pc98-i386sx-busybox-ide.img.xz` | i386SX/DX, static BusyBox | IDE, H=8/S=17 | 5 MiB | below 40 MB |
| `linux-pc98-i386sx-busybox-scsi55.img.xz` | i386SX/DX, static BusyBox | PC-9801-55-compatible SCSI, H=8/S=17 | 5 MiB | below 40 MB |
| `linux-pc98-i386sx-busybox-scsi92.img.xz` | i386SX/DX, static BusyBox | PC-9801-92 SCSI, H=8/S=32 | 5 MiB | below 40 MB |
| `linux-pc98-i486dx-debian13-ide.img.xz` | i486DX or newer, Debian 13/i486 | IDE, H=8/S=17 | 64 MiB | below 2 GB |
| `linux-pc98-i486dx-debian13-scsi55.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-55-compatible SCSI, H=8/S=17 | 64 MiB | below 2 GB |
| `linux-pc98-i486dx-debian13-scsi92.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-92 SCSI, H=8/S=32 | 64 MiB | below 2 GB |

Use a `scsi55` image for PC-9801-55-compatible adapters such as WINnote98.
Use a `scsi92` image for PC-9801-92 and compatible adapters whose BIOS uses
H=8/S=32. SCSI images include `rootwait`, allowing slow real adapters to
finish controller initialization and target discovery before Linux mounts the
root filesystem.

The IDE and SCSI archives are deliberately separate because the native PC-98
partition table stores CHS coordinates. Do not interchange H=8/S=17 and
H=8/S=32 images.

## Windows qemu-pc98

`qemu-pc98-win64.zip` contains x86_64 and i386 QEMU system binaries,
`virtpc98.exe`, runtime DLLs including libusb support, and the free PC-98
compatibility BIOS files. The compatible SCSI BIOS is installed below the
`pc98bios` directory used by QEMU.

## Standalone files

- `vmlinux-i386` — low-memory i386SX Linux 7.1 kernel.
- `vmlinux-i486-debian` — Linux 7.1/i486DX kernel used by the Debian images.
- `ipl-lba0.img` — silent LBA 0 PC-98 disk IPL.
- `ipl-lba2.img` — LBA 2 BOOT98 first stage.
- `boot98.bin` and `boot98.cfg` — BOOT partition loader and default script.
- `linux98.exe` — DOS command-line Linux loader.

Copy `LINUX98.EXE` and an uncompressed `VMLINUX` to a DOS-accessible FAT
volume and run:

```text
LINUX98 VMLINUX root=/dev/sda2 rootfstype=ext4 rw
```

Run it from plain real-mode DOS. Memory managers or other software that has
already entered protected mode can prevent the loader from taking control.
The root device must match the selected IDE or SCSI image.

## Reproducible build

All public files are generated through one command:

```sh
./build.sh release --version v0.6.0
```

Use `--publish-rootfs-cache` when the maintainer also intends to refresh the
verified reusable BusyBox and Debian/i486 root filesystem archives on the
package server.

# Linux/PC-98 v0.12.0

This release improves hard-disk boot compatibility on later PC-9821 systems
and adds optional PEGC emulation to qemu-pc98 and the VirtPC98 frontend.

## Highlights

- Native PC-98 disk images now carry both this project's `IPL1` marker and
  the trailing `55 AA` signature required by firmware on systems such as the
  PC-9821Ra43.
- Linux still gives a valid NEC98 partition table priority when `IPL1` is
  present, so the added signature does not cause these disks to be parsed as
  ordinary PC/AT MBR disks.
- qemu-pc98 adds optional full PEGC support for the `pc9821` machine. Enable
  it with `-M pc9821,pegc=on` when a guest needs the 640x480 256-colour PEGC
  path, such as the PC-98 edition of Windows 2000.
- PEGC remains disabled by default. Enabling it reserves the 16 MiB system
  space and therefore exposes 1 MiB less low memory to the guest. It requires
  QEMU's compatibility BIOS and is not available on the `pc9801` machine.
- VirtPC98 now provides Machine and Graphics selectors. PC-9801 is restricted
  to GDC, while PC-9821 can select GDC, Cirrus, or PEGC plus Cirrus. Selecting
  PEGC automatically selects the compatible BIOS.
- zedBSD bootloader and image-generation updates are included, together with
  refreshed BusyBox and Debian 13/i486 disk images.

## Choosing a disk image

| Image | CPU and userland | Interface and geometry | Minimum RAM |
| --- | --- | --- | ---: |
| `linux-pc98-i386sx-busybox-ide.img.xz` | i386SX, static BusyBox | IDE, H=8/S=17 | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi55.img.xz` | i386SX, static BusyBox | PC-9801-55 compatible SCSI, H=8/S=17 | 5 MiB |
| `linux-pc98-i386sx-busybox-scsi92.img.xz` | i386SX, static BusyBox | PC-9801-92 SCSI, H=8/S=32 | 5 MiB |
| `linux-pc98-i486dx-debian13-ide.img.xz` | i486DX or newer, Debian 13/i486 | IDE, H=8/S=17 | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi55.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-55 compatible SCSI, H=8/S=17 | 64 MiB |
| `linux-pc98-i486dx-debian13-scsi92.img.xz` | i486DX or newer, Debian 13/i486 | PC-9801-92 SCSI, H=8/S=32 | 64 MiB |

Write the appropriate decompressed image byte-for-byte to a CF card, SD
adapter, SCSI2SD, BlueSCSI, or another block device. Writing an image destroys
the existing contents of that device.

The images now include the boot marker expected by conventional raw-image
writers and later PC-9821 firmware; Rufus's Ignore Boot Marker option is no
longer required.

## Boot behavior

BusyBox images load `VMLINUX` directly from the FAT16 BOOT partition through
bootsimple. Debian images boot zedBSD first and offer Linux, Remacs, Holoris,
and a shell in the graphical menu.

The Debian Linux action is:

```text
/bin/linux /vmlinux root=PARTLABEL=DEBIAN13 rootfstype=ext4 rw rootwait
```

## Other artifacts

- `vmlinux-i386` is the low-memory Linux 7.1 kernel for i386SX systems.
- `vmlinux-i486-debian` is the Linux 7.1/i486DX Debian kernel.
- `bootsimple.zip` contains the IDE/SCSI55/SCSI92 direct loaders, source,
  installer, verifier, tests, and exact release command lines.
- `bootloader.zip` contains the zedBSD PC-98 loader distribution and DOS tools.
- `qemu-pc98-win64.zip` contains Windows qemu-pc98 binaries, compatibility
  BIOS, required DLLs, and the VirtPC98 frontend.
- `SHA256SUMS` authenticates every uploaded binary artifact.

## Reproducible build

The complete release artifact set is generated with:

```sh
./build.sh release --version v0.12.0
```

The release uses zedBSD commit `e4a2c2b`, Noct commit `487ddfc`, qemu-pc98
commit `43f2081`, and debian-i486 commit `a1e431e`.
